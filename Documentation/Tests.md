# Tests

Each test you create either for frontend and backend should follow this rules.

## Conditions for creating a test

* You need to test if the feature you just developed is working properly.
* You already added at least one full-fledged feature.
* The feature is theoretically working and you want to test it in a simulated real scenario.

or

* Something is failing and you need to add some test(s) to make the fix.

## Rules for creating a test

* You need to test only one feature at a time.
